DataBridge — GAS Modular CRUD Framework

Penjelasan arsitektur codebase dalam diagram Mermaid · Google Apps Script + Google Spreadsheet sebagai database

1. Ringkasan Codebase

Apa yang sebenarnya dibangun proyek ini?

  • Framework CRUD modular berjalan penuh di Google Apps Script (V8) — tanpa npm, tanpa bundler, tanpa React/Vue.
  • Google Spreadsheet adalah database-nya; semua tabel (Users, Products, Categories, Roles) adalah sheet.
  • Configuration-driven: satu objek Schema menjadi single source of truth untuk kolom tabel, form, validasi, prefix ID, dan mapping sheet.
  • RAM Cache via CacheService memangkas latensi baca dari ~1500ms ke ~5ms, dengan auto-invalidation pada setiap mutasi.
  • RBAC end-to-end: dicek ganda di client (Auth.can) dan server (RBAC.authorize) per resource × action.
  • Entitas yang sudah ada: Users Products Categories Roles — sedangkan Orders masih tab placeholder (siap dikembangkan sesuai protokol ekspansi).

  • Resilient Header Mapping — urutan kolom sheet boleh diubah admin; aplikasi tidak rusak karena tidak ada row[0]/row[1] di luar 10_Database.gs.
  • ID otomatis oleh Repository.create: cari max sequence lalu Utils.generateId → USR-000001, PRD-000001, CAT-000001.
  • Timestamps otomatis: created_at & updated_at diisi Repository, bukan oleh caller.

9. Aturan Emas (Strict Don'ts)

Pelanggaran aturan ini merusak arsitektur framework.

  • 🚫 SpreadsheetApp hanya boleh di 10_Database.gs — bypass = cache basi (stale).
  • 🚫 Komponen/Tab dilarang memanggil google.script.run langsung — wajib via API.html (Promise).
  • 🚫 Dilarang menulis <?!= include('File_Belum_Ada'); ?> — template GAS mengevaluasi dan langsung crash.
  • 🚫 Controller wajib try-catch + Response.error() — tidak boleh ada unhandled exception ke client.
  • 🚫 LockService pada operasi mutasi/pembuatan ID tidak boleh dihapus.
  • 🚫 Component_*.html harus tetap 100% entity-agnostic.
  • 🚫 Zero heavy build dependencies — vanilla JS ES6+ dan Tailwind CDN saja.
